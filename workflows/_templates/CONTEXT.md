# Reusable run starters

Copy `run/` to a fresh scratch directory using the [run contract](../run-workspace.md).
The files are templates, not completed work:

- [request.md](run/request.md) records the unit of work and its input paths.
- [status.md](run/status.md) records progress, outputs, and unresolved work.
- [verification.md](run/verification.md) records executed checks and their results.
- [review-coverage.md](review-coverage.md) is copied into lint runs to track
  bounded page and section reviews.

Refresh additionally uses its existing [assessment](../maintenance/refresh/templates/assessment.md)
and [proposal](../maintenance/refresh/templates/proposal.md) templates.
Page authors use the canonical [schema templates](../../wiki/SCHEMA.md#page-format).
Keep reusable instructions here and run-specific material in the copied folder.
